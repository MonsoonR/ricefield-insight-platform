# 用户手册

## 场景驾驶舱

查看当前数字孪生场景、健康度、地块数量、指标数量、观测天数、预警数量、区域预警、质量状态分布和近期预警。点击“进入 Cesium 地图”可进入地块空间分析。

## Cesium 地图孪生

选择指标、日期和区域后，地图按指标值和质量状态给地块着色。点击地块可查看当前值、观测批次、数据来源、趋势和关键指标。图例按正常、关注、预警、严重和无数据区分状态。

## 地块画像

选择单个地块，查看地块概要、基础信息、地图定位、多指标快照、趋势图、数据来源追溯和质量状态汇总。

## 指标对比

选择指标、日期和区域，查看各地块排行、区域对比、状态分布和明细表，用于发现地块间差异与异常状态。

## 预警分析

查看关注、预警和严重状态对应的风险事件。可按指标、区域和类型筛选，并在地图上定位地块。

## 系统说明

查看平台定位、当前模拟数据说明、数字孪生构建流程、系统功能边界、后续演进方向和项目文档索引。
