# 用户手册

## 适用用户

本文档面向研究所研究人员、项目维护人员和数据管理员。

## 计划覆盖的使用场景

| 场景 | 说明 |
|---|---|
| 查看首页总览 | 查看当前数据批次、地块数量、异常数量和导入状态 |
| 使用地图分析工作台 | 在卫星底图上查看地块边界、指标着色和地块详情 |
| 查看地块详情 | 查看单个地块的趋势、来源和异常记录 |
| 对比指标 | 对比不同地块、区域和指标的趋势差异 |
| 查看导入质量报告 | 定位缺失值、异常值、未匹配地块和错误单元格 |
