# 用户手册

## 场景驾驶舱

查看当前数字孪生场景编号、中文场景名、最近观测日期、地块数量、指标数量、预警数量、观测天数和孪生健康度。首页还提供作物长势、叶绿素、氮、pH、LAI 的关键指标概览，展示最新值、单位、近 7 次趋势和状态。

风险状态分布按正常、关注、预警、严重四级汇总；区域状态展示试验一区、试验二区的地块数量和预警数量。点击“进入 Cesium 地图孪生”可进入地块空间分析；点击预警入口可进入预警分析；点击重点关注地块可进入对应地块画像。

## Cesium 地图孪生

选择指标、日期和区域后，地图按指标值和质量状态给地块着色。点击地块可查看当前值、观测批次、数据来源、趋势和关键指标。图例按 normal 正常、watch 关注、warning 预警、critical 严重和无数据区分状态。

## 地块画像

选择单个地块，查看地块概要、基础信息、地图定位、多指标快照、趋势图、数据来源追溯和质量状态汇总。

## 指标对比

选择指标、日期和区域，查看各地块排行、区域对比、状态分布和明细表，用于发现地块间差异与异常状态。

## 预警分析

查看 watch 关注、warning 预警和 critical 严重状态对应的风险事件。可按指标、区域和类型筛选，并在地图上定位地块。

## 系统说明

查看平台定位、当前模拟数据说明、数字孪生构建流程、系统功能边界、后续演进方向和项目文档索引。
