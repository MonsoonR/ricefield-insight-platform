# 系统架构

## 目标

稻田智研平台面向水稻试验田数据研究，核心目标是把 Excel、GeoJSON 等来源的数据整理为统一结构，并通过地图、图表、表格和质量报告支持研究分析。

## 总体分层

| 层级 | 职责 |
|---|---|
| 前端展示层 | 地图分析、指标筛选、趋势图、表格、导入状态和质量报告展示 |
| API 层 | 对外提供稳定的 HTTP 接口，只处理请求参数、响应结构和错误信息 |
| 服务层 | 承载业务规则，包括指标筛选、地块匹配、趋势查询、质量报告组织 |
| 数据处理层 | 解析 Excel、GeoJSON，执行字段标准化、单位处理、质量检查 |
| 数据存储层 | MVP 阶段使用标准化 JSON / CSV / 可选 SQLite；正式阶段接入 PostgreSQL + PostGIS |
| 部署层 | 面向内网部署，使用 Nginx 和 Docker Compose 组织服务 |

## MVP 边界

MVP 优先完成六件事：

1. Excel 数据解析。
2. 地块 GeoJSON 加载。
3. Cesium 地图展示。
4. 指标筛选与地块着色。
5. 点击地块查看趋势。
6. 导入质量报告。

用户权限、复杂统计分析、自动研究报告、三维地形、多时相遥感图层和多项目管理暂缓到后续阶段。

## 模块边界

后端业务逻辑应优先放在服务层，路由函数只处理 HTTP 输入输出。前端不直接依赖 Excel 原始结构，只消费后端返回的标准化数据。数据导入必须生成质量报告，不能把缺失值、未匹配地块、异常单位等问题隐藏在界面之后。
