# 设计系统

## 设计目标

界面应中文优先，适合科研数据分析场景。整体风格应清晰、易读、高效，支持地图、图表、表格和质量报告在同一平台内保持一致体验。

## 基础原则

| 原则 | 说明 |
|---|---|
| 信息优先 | 页面优先服务数据查看、筛选、比较和定位 |
| 状态明确 | 无数据、异常、警告、导入中、导入失败等状态必须清楚表达 |
| 密度适中 | 面向研究人员的工作台可以承载较多信息，但不能牺牲可读性 |
| 组件复用 | 筛选器、图表容器、表格、空状态、错误状态应形成统一写法 |
| 地图友好 | 地块着色、悬浮提示、点击详情和图表联动需要保持稳定交互 |

## 需要规范的内容

- 主色、辅助色、成功色、警告色、错误色。
- 无数据颜色、异常颜色、地图色阶、图表色板。
- 页面标题、区块标题、表格文字、图表标签、地图 tooltip。
- 页面间距、卡片间距、表单布局、图表容器高度、地图容器高度。

## 建议沉淀的基础组件

后续前端初始化后，可根据实际页面沉淀以下组件：`PageContainer`、`FilterBar`、`MetricSelector`、`DateSelector`、`RegionSelector`、`ChartCard`、`CesiumMapPanel`、`DataTable`、`EmptyState`、`ErrorState`、`ImportStatusTag`、`MetricValueTag`。
