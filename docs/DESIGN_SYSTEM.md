# 设计系统

## 设计目标

界面服务于科研演示和大创答辩，强调清晰、可信、可讲述。页面不做营销化 hero，不堆装饰卡片，优先展示地图、指标、趋势、状态和预警。

## 页面结构

| 页面 | 设计重点 |
|---|---|
| 场景驾驶舱 | 场景说明、健康度、状态卡片、区域预警和指标排行 |
| Cesium 地图孪生 | 地图为主，右侧地块详情，下方趋势和表格 |
| 地块画像 | 单地块基础信息、地图定位、多指标趋势和来源追溯 |
| 指标对比 | 指标排行图和对比表 |
| 预警分析 | 预警地图、预警列表和类型分布 |
| 系统说明 | 文档索引和维护提示 |

## 视觉规范

- 主色使用稻田科研绿色 `#1F7A4D`。
- 预警使用橙色，异常使用红色，正常使用绿色。
- 卡片圆角不超过 8px。
- 地图区域必须明显大于辅助图表。
- 中文优先，控件文字简洁。

## 组件规范

- 页面使用 `PageContainer`。
- 筛选器使用 `FilterBar`、`MetricSelector`、`DateSelector`、`RegionSelector`。
- 图表使用 `ChartCard + EChartView`。
- 表格使用 `DataTable`。
- 状态使用 `StatusTag` 和 `MetricValueTag`。
- 地图统一通过 `CesiumMapPanel`。

## 地图规范

- 默认使用卫星底图。
- 地块 polygon 半透明，边界线清晰。
- 点击地块必须联动右侧详情。
- 缺失地块使用灰色/虚线，异常地块使用橙红高亮。
