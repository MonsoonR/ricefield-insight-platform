# 设计系统

本设计系统是稻田智研平台所有页面的视觉与交互基线。新增或修改页面前必须先阅读本文件；调整视觉风格、新增组件或修改通用样式时，必须先更新本文件，再改代码。页面不得各自定义私有视觉规范。

## 1. 平台视觉定位

- 稻田数字孪生平台 / 智慧农业监测系统 / 科研展示型业务系统。
- 设计基调：清爽、可信、专业。强调数据可读性、地图与图表可信度。
- 不做营销化 hero、不做酷炫大屏、不堆装饰卡片。仅在场景驾驶舱顶部允许使用一条轻量场景横幅。
- 信息密度适中，优先展示地块、指标、状态、趋势和预警。
- 中文优先。控件文字简洁，避免营销化措辞与旧导入平台残留概念。

| empty | 无数据 | `--rf-status-empty` | `#6B7280` | `#F1F5F3` | `#E8EEF0` |

### 2.3 后端 quality_flag 到状态映射

后端字段 `quality_flag` 不变，前端通过 `src/utils/status.ts` 中的 `mapQualityToStatus()` 做映射：

| 后端值 | 前端等级 | 文案 |
|---|---|---|
| `normal` / `success` | normal | 正常 |
| `missing` | watch | 关注 |
| `outlier` / `abnormal` | warning | 预警 |
| `error` | critical | 严重 |
| `empty` / `no_data` / 其它 | empty | 无数据 |

### 2.5 KPI 图标 Tone

`StatCard` 的 tone 仅影响图标圆形背景，不影响文字。可选：`green` / `cyan` / `blue` / `purple` / `yellow` / `orange` / `red`。默认 `green`。

## 3. 排版与间距

- 字体：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`
- 字号阶梯：`12 / 13 / 14 / 16 / 18 / 22 / 28 / 36`
  - 12：辅助说明、表格脚注
  - 13：次文字、副标题、表格表头
  - 14：正文、表格内容
  - 16：卡片标题
  - 18：分区小标题
  - 22：页面主标题
  - 28-36：KPI 大数字
- 字重：常规 500、标题 700、KPI 数字 800
- 行高：正文 1.55、标题 1.3、KPI 数字 1.1
- 圆角：卡片 12px（`--rf-radius-lg`）、按钮/标签 6px（`--rf-radius`）、图标圆 50%
- 阴影：仅一级阴影 `0 1px 2px rgba(15, 56, 37, .04), 0 1px 3px rgba(15, 56, 37, .06)`，不叠加多层。
- 间距阶梯：`4 / 8 / 12 / 16 / 20 / 24 / 32`，页面主体 padding `28px`，卡片之间 `16-20px`。

## 4. 页面布局规范

### 4.1 全局骨架

- 左侧导航：固定 240px，白底 `--rf-surface`，不得使用深色底。
- 顶部栏：固定 64px，白底 + 底部 1px 描边。左侧放当前页面标题与副标题，右侧固定四件套：天气、通知、文档入口、用户头像。
- 主体：背景 `--rf-bg`，内边距 `28px`，使用 `flex column`，块间距 `20px`。
- 不使用深色背景大屏样式。

### 4.2 数据页面三段式

所有数据页（除地图与系统说明）按这个顺序：

1. **筛选区**：`FilterBar`（指标对比、预警分析、地图、地块画像必备）。
2. **KPI 行**：4 个 `StatCard`，等宽。
3. **主可视化区**：`ChartCard` 或 `CesiumMapPanel`。可与右侧次级面板组合，主图占比不少于 60%。
4. **明细表**：`DataTable`。

### 4.3 例外页面

- **场景驾驶舱**：首屏使用稻田数字孪生场景横幅，展示场景编号、中文场景名、最近观测日期和地图/预警入口。横幅背景必须使用 CSS 渐变、SVG 或程序化图形，不使用来源不明的真实图片。
- **场景驾驶舱 KPI**：横幅下方使用 5 个精炼指标卡，固定覆盖地块数量、指标数量、预警数量、观测天数和孪生健康度；数字必须突出，说明文案不超过两行。
- **场景驾驶舱概览模块**：关键指标概览固定优先展示作物长势、叶绿素、氮、pH、LAI，包含最新值、单位、近 7 次趋势和状态；风险状态分布必须使用 `正常 / 关注 / 预警 / 严重` 四级；区域状态至少展示试验一区和试验二区的地块数量与预警数量；重点关注地块必须可进入地块画像。
- **Cesium 地图孪生**：地图必须是视觉中心，最小高度 560px，右侧附 320-360px 详情面板。
- **地块画像**：三栏布局（基础信息 / 地图定位 / 指标快照），下方接趋势与来源表。
- **指标对比**：筛选 + KPI 行 + 排行图 + 明细表三段式。
- **预警分析**：地图 + 状态面板 + 列表 + 类型分布。
- **系统说明**：搜索区 + 文档目录表 + 推荐文档 + 维护提示。

## 5. 组件规范

所有页面必须复用 `src/components/base/` 的公共组件，不允许私有重复实现。

### 5.1 PageContainer

- 顶部标题区：标题 22px Bold + 副标题 13px muted。CTA 放在右侧。
- 标题与下方块的间距 20px。

### 5.2 SidebarNav (`AppSidebar`)

- 白底，宽 240px。
- 顶部品牌：绿色方形 logo（主色渐变）+ 平台名 + 副标题。
- 链接：左 padding 14px，行高 44px，左侧 3px 高度 24px 的指示条（默认透明，激活态主色）。
- 激活态：背景 `--rf-primary-soft`，文字 `--rf-primary`，左侧指示条显示。
- 悬停态：背景 `--rf-surface-soft`，文字 `--rf-text`。
- 底部仅显示版本号，不放装饰卡片。

### 5.3 AppHeader

- 左侧：当前页面标题 + 副标题（由路由 meta 提供）。
- 右侧固定四件套：`天气（静态 26°C ☀ 晴）` → `通知 Bell（带角标）` → `文档 QuestionCircle` → `用户头像 + 角色名`。
- 不放置全局筛选器。所有筛选器在各自页面的 `FilterBar` 中。

### 5.4 StatCard

- 高度 108px，左圆形 tinted icon（44px），右侧三段：label / value / note。
- value 字号 28px Bold 800；label 13px muted；note 12px soft。
- 圆形图标背景 `color-mix(in srgb, var(--tone) 14%, white)`，图标颜色 `var(--tone)`。
- 6 种 tone 见 §2.5。

### 5.5 ChartCard

- 顶部 padding `16px 20px`，标题 16px + 副标题 12px。
- 图表区域 padding `16px 20px`。
- 卡片整体使用 `var(--rf-radius-lg)` 圆角，描边 `var(--rf-border-soft)`，背景白。

### 5.6 FilterBar

- 浅灰底 `--rf-surface-soft`，描边 `--rf-border-soft`，圆角 12，padding `14px 16px`。
- 控件之间间距 12px，右侧放 `查询`（`type=primary`）+ `重置`（描边款）。

### 5.7 StatusTag

- 胶囊圆角 999px，padding `2px 10px`，字号 12，字重 700。
- 4 级状态：背景使用 tint，文字使用主色。

### 5.8 MetricValueTag

- 显示 `值 + 单位`，按 quality_flag 映射的状态着色。
- 表格中使用紧凑款（padding 3px 8px），KPI 中使用大字款（28px+）。

### 5.9 DataTable

- 表头使用 `--rf-surface-soft` 背景，表头字号 13，字重 700。
- 行高 48px，行分割线 `--rf-border-soft`。
- 操作列固定在最右，使用描边款小按钮（如 `查看画像`、`定位地图`）。

### 5.10 CesiumMapPanel

- 最小高度 560px（详情页可降低到 320px），地图容器圆角 12，溢出隐藏。
- 必须提供：左浮动工具条、左下图例、右下比例尺占位。
- 选中地块描边使用 `--rf-status-warning`，宽度 3，正常地块按 quality_flag 着色。
- 必须提供右侧地块详情面板。

## 6. 图表规范

### 6.1 通用配置

- ECharts grid 默认：`top: 32, right: 24, bottom: 36, left: 48`。
- `xAxis` / `yAxis`：`axisLine.show: false`，`splitLine` 颜色 `#EDF2EF`。
- `tooltip`：light 主题，圆角 8，描边 `--rf-border-soft`。
- `legend`：默认顶部居中，字号 12。

### 6.2 颜色

| 用途 | 颜色 |
|---|---|
| 主指标值（柱、折线） | `--rf-primary` `#15905D` |
| 次指标值 / 对比线 | `--rf-accent-cyan` `#0E9F8C` |
| 正常占比 | `--rf-status-normal` `#16A36A` |
| 关注 | `--rf-status-watch` `#C58B04` |
| 预警 | `--rf-status-warning` `#EA580C` |
| 严重 | `--rf-status-critical` `#DC2626` |

### 6.3 折线 / 柱状

- 折线：`smooth: true`，宽度 2.5，节点 `symbolSize: 6`，区域填充 `rgba(21, 144, 93, 0.10)`。
- 柱状：圆角顶部 4，宽度 28-40。

### 6.4 反例

- 不堆叠 5 个以上系列在同一图。
- 不使用彩虹色随机配色。
- 首页只放概览图（排行、分布、趋势），详情页才放解释性多系列图。

## 7. 地图规范

- Cesium 页面地图必须是视觉中心，最小高 560px。
- 地块边界使用 `--rf-border` 加 0.6 alpha 边线；选中态描边 `--rf-status-warning`，宽度 3。
- 地块填充按 quality_flag 状态色，正常地块使用主色 30% 透明度。
- 必须提供图例（4 级状态色块 + 文案）和右侧地块详情面板。
- 异常 / 严重地块在地图上必须高亮（增加发光描边）。

## 8. 文案规范

- 全部使用中文。
- 状态等级统一使用 `正常 / 关注 / 预警 / 严重`，禁止裸露后端字段（`outlier`、`missing`、`error`）。
- 禁用词：`数据导入中心`、`Excel 报告`、`source cell`、`源单元格`、`导入批次`（→ 用 `观测批次`）、`导入质量报告`（→ 用 `数据质量`）。
- 副标题和说明文案以 1-2 行为限，避免堆砌。

## 9. 后续约束

1. 新页面必须：
   - 使用 `PageContainer` 包裹；
   - 走全局 CSS 变量 `--rf-*`，不写死颜色值；
   - 状态展示走 `StatusTag` / `MetricValueTag` 与 4 级状态映射；
   - 数据页采用三段式布局；
   - 图表配色和 grid 走本规范默认值。
2. 修改视觉风格（颜色、间距、组件结构、布局骨架）必须先更新本文件，再改代码；同一次提交内同步。
3. 不允许在页面级 `<style scoped>` 中覆盖 token 颜色。需要新颜色时先在本文件登记并加入 `global.css`。
4. 新增组件进入 `src/components/base/` 前必须在本文件第 5 章登记其规范。
5. CHANGELOG 必须记录视觉规范的每次修改。
## 10. Cesium 地图孪生页面规范

- 页面定位：`Cesium 地图孪生` 是系统核心空间分析页面，地图必须是首屏视觉中心；右侧详情、下方趋势图、关键指标表和最新观测记录只用于解释地图状态。
- 布局：主体使用 `地图主区域 + 右侧详情面板 + 下方分析区`。地图区域最小高度 620px，宽度优先占满主列；右侧面板宽度 320-360px；下方分析区采用左趋势图、右关键指标表、下方观测记录表。
- 顶部筛选：指标、日期、区域、查询、重置放在地图内部顶部浮层。浮层使用白底半透明、轻阴影、紧凑间距；查询按钮使用 `--rf-primary`，重置按钮使用白底描边。
- 地图渲染：地块 polygon 填充使用当前指标色阶或质量状态；缺失数据使用灰色低透明度；预警/严重使用橙色或红色突出；选中地块使用亮色描边和弱发光；地块编号必须显示在 polygon 中心。
- 图例：地图左下角固定显示当前指标名称和单位、低值到高值色阶、无数据、地块边界、预警/严重说明，不遮挡主要地块。
- 地图工具：保留缩放按钮，并提供定位选中地块、图层透明度、回到默认视角。工具按钮统一白底、8px 圆角、轻阴影、图标化表达。
- 详情面板：点击地块后展示状态标签、地块编号、区域、名称、面积、品种、最近观测、数据来源、观测批次；当前指标数值和较昨日变化必须突出显示。
- 图层控制：右侧下方使用 Ant Design Vue switch，包含地块边界、当前指标渲染、预警地块、区域边界；不提供测距、绘制、编辑、上传或真实 GeoJSON 导入入口。
