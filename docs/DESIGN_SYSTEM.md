# 设计系统

## 设计目标

界面服务于科研演示和大创答辩，强调清晰、可信、可讲述。页面不做营销化 hero，不堆装饰卡片，优先展示地图、指标、趋势、状态和预警。

本轮视觉优化参考 `docs/design-reference/` 中的效果图，统一沉淀为“浅色科研工作台 + 绿色农业数字孪生”的平台风格。后续页面开发应先复用本文件规范，避免页面各自形成独立风格。

## 页面结构

| 页面 | 设计重点 |
|---|---|
| 场景驾驶舱 | 顶部场景横幅、健康度、状态卡片、区域预警、质量状态和近期预警 |
| Cesium 地图孪生 | 地图为视觉中心，右侧地块详情，下方趋势、摘要和关键指标表 |
| 地块画像 | 顶部地块概要、基础信息、地图定位、多指标快照、趋势和来源追溯 |
| 指标对比 | 筛选条件、统计卡片、地块排行、区域对比、状态分布和明细表 |
| 预警分析 | 预警统计、地图分布、地块状态、预警列表和类型分布 |
| 系统说明 | 平台定位、当前数据说明、数字孪生构建流程、系统边界和文档索引 |

## 视觉规范

- 主色使用稻田科研绿色 `#15905D`，深绿色使用 `#0B6B45` / `#064A33`，浅绿色背景使用 `#E8F6EF`。
- 页面背景使用 `#F6F8F7`，主内容卡片使用白色，边框使用 `#EDF2EF`，阴影使用低透明绿色阴影。
- 左侧导航使用浅色固定侧栏，当前页面使用浅绿色底色和左侧绿色高亮条。
- 顶部栏只展示全局状态、预警入口、文档入口和演示用户，不放置不可操作的全局筛选器。
- 卡片圆角统一不超过 8px，页面网格间距默认 16px。
- 标题使用深色高权重中文标题，辅助说明使用灰色小字号，避免营销化口号。
- 地图区域必须明显大于辅助图表；地图容器可使用深色底和半透明图例，强化数字孪生空间感。
- 预警颜色统一：
  - 正常：绿色 `#16A36A`
  - 关注：浅黄 `#F6C343`
  - 预警：橙色 `#F97316`
  - 严重：红色 `#EF3B2D`
  - 无数据：灰色 `#D1D5DB`
- 中文优先，控件文字简洁。

## 组件规范

- 页面使用 `PageContainer`。
- 筛选器使用 `FilterBar`、`MetricSelector`、`DateSelector`、`RegionSelector`。
- 图表使用 `ChartCard + EChartView`。
- 表格使用 `DataTable`。
- 状态使用 `StatusTag` 和 `MetricValueTag`。
- 地图统一通过 `CesiumMapPanel`。
- 筛选器、卡片、图表、表格使用统一的边框、圆角、阴影和标题样式。
- 统计卡片用于关键状态，不把所有说明拆成大量小卡片。
- 表格表头使用浅灰绿色背景，行 hover 使用浅绿色背景。
- 按钮以 Ant Design Vue 为基础，主按钮使用平台绿色。

## 地图规范

- 默认使用卫星底图。
- 地块 polygon 半透明，边界线清晰。
- 点击地块必须联动右侧详情。
- 缺失或无数据地块使用灰色/虚线。
- 关注地块使用浅黄，预警地块使用橙色，严重地块使用红色。
- Cesium 地图页中地图高度优先保障主视觉，图例置于地图内左下角，工具按钮置于地图内右上角。
