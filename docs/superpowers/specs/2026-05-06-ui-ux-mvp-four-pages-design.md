# 稻田数字孪生平台六页 UI/UX 基准

日期：2026-05-17

> 本文档替代 2026-05-06 的四页导入型 MVP 草案。第一阶段不再建设数据导入中心，不展示 Excel、导入报告或客户原始文件来源；页面设计统一服务于大创答辩用数字孪生演示闭环。

## 设计目标

第一版 UI/UX 以“科研数据驾驶舱 + Cesium 地图孪生 + 地块分析闭环”为核心。页面应帮助评审和项目成员快速理解：平台能生成可信稻田场景、在地图上表达地块状态、按指标和时间筛选观测结果，并将质量问题转化为可解释的预警。

## 页面范围

新版前端固定为六页：

1. 场景驾驶舱
2. Cesium 地图孪生
3. 地块画像
4. 指标对比
5. 预警分析
6. 系统说明

## 信息架构

全局采用左侧导航 + 顶部场景状态栏 + 主内容区的后台工作台布局。

左侧导航包含：

- 场景驾驶舱
- Cesium 地图孪生
- 地块画像
- 指标对比
- 预警分析
- 系统说明

顶部状态栏显示：

- 当前演示场景
- 最新观测日期
- 地块数量
- 当前预警数量
- 快速进入地图孪生按钮

## 页面设计

### 场景驾驶舱

用途：在答辩第一屏解释平台当前演示场景、地块规模、指标覆盖、观测周期和预警状态。

核心区域：

- 场景摘要卡片：场景名称、地块数量、指标数量、预警数量。
- 指标概览：长势、叶绿素、氮磷钾、pH、有机质、盐分、LAI、株高、成熟期预测等。
- 当前预警摘要：按严重程度展示质量问题。
- 快捷入口：进入地图孪生、指标对比、预警分析。

### Cesium 地图孪生

用途：MVP 核心页面，用 Cesium 承载程序生成地块边界、指标着色和趋势联动。

核心区域：

- 顶部筛选栏：指标、日期、区域、地块关键字。
- 主地图区：卫星底图、地块边界、指标色阶、异常高亮、无数据样式。
- 地图工具：定位首个地块、清除选择、刷新图层。
- 右侧地块详情面板：选中地块摘要、当前指标值、观测批次、数据来源。
- 下方趋势图和关键指标表。

交互重点：

- 切换指标或日期后，地图地块颜色同步更新。
- 点击或定位地块后，详情面板、趋势图、指标表同步更新。
- 质量异常在地图、趋势和表格中保持一致表达。

### 地块画像

用途：查看单个地块的完整指标画像和时序趋势。

核心区域：

- 地块基础信息：编号、区域、面积、作物品种、最新观测时间。
- 多指标当前值表。
- 单指标趋势图。
- 观测批次与数据来源字段。
- 质量标记和预警提示。

### 指标对比

用途：按指标、日期和区域比较不同地块的观测值，支持展示空间差异和排序结果。

核心区域：

- 指标、日期、区域筛选。
- 地块指标排行图。
- 指标对比明细表。
- 异常地块数量统计。

### 预警分析

用途：集中展示 DataQualityIssue 语义下的缺失值、异常值、临界值和地块风险。

核心区域：

- 预警总览：总数、严重数量、涉及地块、涉及指标。
- 按严重程度和指标筛选。
- 预警列表。
- 地图预警图层入口。

### 系统说明

用途：说明演示平台边界、数据生成方式、接口能力、PostGIS 可选正式层和后续扩展方向。

核心区域：

- 项目定位。
- 当前六页闭环。
- 数据生成与治理原则。
- API 与文档索引。
- 第一阶段明确不包含的数据导入、真实客户数据和自动报告能力。

## 视觉方向

整体风格采用科研分析工作台，不做营销化首页。主色以稻田绿色为核心，配合中性灰、数据蓝和预警橙红，保证地图、图表和表格统一。

建议色彩：

- 主色：稻田绿，用于主要操作、健康状态和地块有效值。
- 辅色：数据蓝，用于图表、信息层级和系统状态。
- 警告：橙色，用于临界值和待关注质量问题。
- 错误：红色，用于严重异常。
- 无数据：中性灰，用于地图地块和空状态。

## 组件约束

前端实现优先映射到 Ant Design Vue：

- Layout / Menu / Breadcrumb
- Card / Statistic / Table / Tag
- Select / Segmented / Button
- Drawer / Tabs / Alert
- ECharts 图表容器
- Cesium 地图容器

## MVP 边界

本阶段不包含：

- Excel、GeoJSON、PDF、图片等真实文件导入。
- 数据导入中心。
- 导入质量报告。
- 权限系统。
- 多项目管理。
- 自动报告生成。
- 复杂三维地形。
- 遥感多时相图层。
- 复杂空间分析。

这些能力进入第二阶段后再单独评估和设计。
