# 稻田智研平台 MVP 四页 UI/UX 设计说明

日期：2026-05-06

## 设计目标

第一版 UI/UX 以“科研分析工作台”为核心，不做营销化首页。页面要服务水稻试验田数据的导入、质量检查、地图定位、指标筛选、地块趋势查看和来源追溯。

## 页面范围

本次 Figma 草图覆盖 4 个 MVP 页面：

1. 总览首页
2. 地图分析工作台
3. 数据导入中心
4. 地块详情页

## 信息架构

全局采用左侧导航 + 顶部状态栏 + 主内容区的后台工作台布局。

左侧导航包含：

- 总览首页
- 地图分析
- 数据导入
- 地块详情
- 文档入口

顶部状态栏显示：

- 当前导入批次
- 最近观测日期
- 数据质量状态
- API/系统状态

## 页面设计

### 总览首页

用途：帮助研究人员和维护人员快速判断当前数据是否可用。

核心区域：

- 数据批次、地块总数、有数据地块、异常地块四个指标摘要
- 最近导入批次与质量状态
- 主要指标概览
- 数据质量提醒列表
- 快捷入口：进入地图分析、查看导入报告、定位异常地块

### 地图分析工作台

用途：MVP 核心页面，用地图承载地块定位、指标着色和趋势联动。

核心区域：

- 顶部筛选栏：区域、指标、日期、质量标记
- 主地图区：卫星底图占位、地块边界、指标色阶、异常高亮、无数据样式
- 地图工具：定位、重置视角、图层切换、色阶说明
- 右侧地块详情面板：选中地块摘要、当前指标值、趋势图、来源追溯、异常提示

交互重点：

- 切换指标或日期后，地图地块颜色同步更新
- 点击地块后，右侧面板显示趋势和来源信息
- 异常地块在地图和详情面板中保持一致提示

### 数据导入中心

用途：让用户明确每次导入是否可信，不能隐藏缺失、异常和未匹配问题。

核心区域：

- 导入批次列表
- 批次质量摘要：成功记录、缺失值、异常值、未匹配地块、解析错误
- 问题明细表：来源文件、工作表、单元格、问题类型、处理状态
- 质量报告详情面板

### 地块详情页

用途：查看单个地块的完整指标画像和来源追溯。

核心区域：

- 地块基础信息：编号、区域、数据完整度、最近观测时间
- 小地图定位
- 多指标趋势图
- 指标当前值表格
- 来源追溯表：批次、文件、工作表、单元格、质量标记
- 异常记录列表

## 视觉方向

整体风格采用白底、蓝灰结构色、深绿主色和橙红异常提示，符合科研数据分析场景。

建议色彩：

- 主色：深绿，用于主操作和健康状态
- 辅色：蓝灰，用于导航、边框和信息层级
- 警告：橙色，用于质量提醒
- 错误：红色，用于解析错误或严重异常
- 无数据：浅灰，用于地图地块和空状态

## 组件约束

后续前端实现应优先映射到 Ant Design Vue：

- Layout / Menu / Breadcrumb
- Card / Statistic / Table / Tag
- Select / DatePicker / Segmented / Button
- Drawer / Tabs / Alert
- ECharts 图表容器
- Cesium 地图容器

## MVP 边界

本次设计不包含：

- 权限系统
- 多项目管理
- 自动报告生成
- 复杂三维地形
- 遥感多时相图层
- 复杂空间分析

这些能力进入第二阶段后再单独设计。
