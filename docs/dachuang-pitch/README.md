# 大创立项答辩 PPT

本目录存放“稻田智研平台”参加大学生创新创业训练计划立项申报的答辩材料。

## 文件

- `index.html`：单文件横向翻页 PPT，可直接用浏览器打开。
- `稻田智研平台立项答辩-张焱哲.pptx`：可编辑 PowerPoint 版本，包含 9 页立项答辩内容和演讲者备注，按约 5 分钟答辩节奏组织。
- `images/`：预留图片目录，后续可放项目截图、地块地图截图或实地照片。

## 操作

- 键盘 `←` / `→` 翻页。
- `ESC` 打开索引页。
- `B` 切换静态低功耗模式，适合投影或性能较弱设备。

## 图片约定

如后续补充图片，建议使用 `{页号}-{语义}.{ext}` 命名，例如 `07-map-workbench.png`、`10-deliverables.png`。截图类图片优先使用 PNG，照片优先使用 JPG。
