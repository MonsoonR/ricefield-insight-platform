# 模拟场景与数据生成指南

> 文件名保留为 `IMPORT_GUIDE.md` 以兼容旧索引，但本文档不再描述 Excel 导入。

## 第一阶段数据来源

默认数据全部由程序生成：

- 地块边界：矩形多边形，WGS84 坐标。
- 指标观测：按生长进程、地块差异和周期扰动生成。
- 预警事件：刻意注入缺失值和异常值，用于演示状态感知。

## 场景参数

| 项 | 值 |
|---|---|
| 场景 ID | `demo-ricefield-2025` |
| 地块数 | 8 |
| 区域 | 试验一区、试验二区 |
| 日期 | 2025-06-01 至 2025-07-15 |
| 指标数 | 11 |
| 预警数 | 6 |

## 质量状态

| 状态 | 含义 |
|---|---|
| `normal` | 正常观测 |
| `missing` | 模拟缺失值 |
| `outlier` | 模拟异常值 |
| `error` | 保留给正式数据层错误状态 |

## 后续真实数据接入原则

后续如接入真实数据，必须先经过合规确认，并转换为 `TwinScenario`、`Plot`、`MetricObservation`、`ObservationBatch`、`DataSource` 和 `DataQualityIssue`。前端仍不得依赖原始文件结构。
