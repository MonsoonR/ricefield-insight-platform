# 指标字典

## 目标

所有指标进入系统前必须先进入指标字典。指标字典用于统一中文名称、编码、单位、数值精度、正常范围、地图色阶和来源类型。

## 字典字段

| 字段 | 含义 |
|---|---|
| metric_code | 指标编码，前后端和数据处理中使用 |
| metric_name | 中文名称 |
| category | 指标类别 |
| unit | 标准单位 |
| value_type | 数值类型 |
| precision | 小数位数 |
| normal_range | 正常范围 |
| color_scale | 地图色阶 |
| description | 指标说明 |
| source_type | 数据来源类型 |

## MVP 关注指标

| 指标 | 类别 | 说明 |
|---|---|---|
| 作物长势 | 作物指标 | 用于描述地块当前长势状态 |
| 成熟期预测 | 作物指标 | 用于比较预测结果稳定性 |
| 叶绿素 | 作物指标 | 用于观察作物生理状态 |
| 氮 | 土壤 / 养分指标 | 用于分析养分水平 |
| 磷 | 土壤 / 养分指标 | 用于分析养分水平 |
| 钾 | 土壤 / 养分指标 | 用于分析养分水平 |
| pH | 土壤指标 | 用于描述酸碱度 |
| 有机质 | 土壤指标 | 用于描述土壤肥力 |
| 可溶性总盐分 | 土壤 / 环境指标 | 用于识别盐分异常 |
| 叶面积指数 | 作物指标 | 用于观察冠层生长 |
| 株高 | 作物指标 | 用于分析生长趋势 |

## 治理规则

同一指标只能有一个稳定 `metric_code`。如果 Excel 中出现同义字段、不同单位或不同写法，应在导入阶段映射到指标字典，并在质量报告中记录转换和异常情况。
