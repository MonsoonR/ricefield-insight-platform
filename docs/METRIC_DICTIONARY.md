# 指标字典

## 第一阶段指标

| 编码 | 名称 | 类别 | 单位 | 用途 |
|---|---|---|---|---|
| `crop_growth` | 作物长势 | 作物指标 | score | 地图默认着色指标 |
| `maturity_prediction` | 成熟期预测 | 作物指标 | 天 | 展示生育进程差异 |
| `chlorophyll` | 叶绿素 | 作物指标 | SPAD | 表征叶片生理状态 |
| `nitrogen` | 氮 | 土壤养分指标 | mg/kg | 表征氮素水平 |
| `phosphorus` | 磷 | 土壤养分指标 | mg/kg | 表征有效磷水平 |
| `potassium` | 钾 | 土壤养分指标 | mg/kg | 表征速效钾水平 |
| `ph` | pH | 土壤指标 | pH | 表征酸碱度 |
| `organic_matter` | 有机质 | 土壤指标 | g/kg | 表征土壤肥力 |
| `soluble_total_salt` | 可溶性总盐分 | 土壤环境指标 | g/kg | 表征盐分压力 |
| `leaf_area_index` | 叶面积指数 | 作物指标 | LAI | 表征冠层生长 |
| `plant_height` | 株高 | 作物指标 | cm | 表征植株高度 |

## 规则

- 所有观测必须引用指标编码。
- 指标色阶用于地图着色。
- 指标正常范围用于解释预警，不直接替代质量状态。
- 新增指标必须同步更新后端指标字典、API 文档和本文件。
