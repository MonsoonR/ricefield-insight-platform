# 第一阶段发布检查清单

## 发布范围

- 发布对象：稻田智研平台第一阶段 MVP，用于大创申报、科研展示、教学演示和内部验收。
- 数据范围：仅使用后端程序生成的 `demo-ricefield-2025` 模拟场景，不接入、不保存、不展示真实客户数据。
- 页面范围：场景驾驶舱、Cesium 地图孪生、地块画像、指标对比、预警分析、系统说明 6 个页面。
- 接口范围：仅开放第一阶段标准化查询 API，覆盖场景、指标、地块、日期、地图图层、地块摘要、地块时序、指标对比和预警分析。
- 数据层范围：默认使用程序生成模拟数据；PostgreSQL + PostGIS 只作为后续正式数据层预留，不作为第一阶段发布依赖。

## 已完成能力

- 后端可生成默认演示场景，包括 8 个示例地块、11 个指标、45 天时序观测和 6 条预警事件。
- 后端可程序生成示例地块边界，前端可在 Cesium 地图中展示地块边界、状态着色、图例和点击详情。
- 前端已形成 6 页演示闭环：总览看场景，地图看空间分布，画像看单地块，指标对比看横向差异，预警分析看质量问题，系统说明看项目边界。
- 地图、画像、指标对比和预警分析支持页面联动，包括定位到地图、查看画像、地块点击和趋势查询。
- 数据质量问题以缺失、异常和错误预警展示，不隐藏缺失值、异常值或解析类问题。
- API 响应不暴露真实 Excel、GeoJSON、PDF、图片或客户来源字段，前端只消费标准化结构。
- 文档已覆盖项目计划、数据模型、指标字典、API 契约、用户手册、演示脚本和变更记录。

## 不做事项

- 不引入真实客户数据，不展示客户 Excel、真实 GeoJSON、客户 PDF、客户图片或其他可识别来源材料。
- 不把 Excel、GeoJSON、PDF、图片导入作为第一阶段主线，也不新增导入中心、导入报告或报告导出页面。
- 不恢复 `/api/imports`、`/api/imports/{id}/report`、`/api/export/report` 等旧版导入导出接口。
- 不新增权限系统、自动报告、多项目管理、复杂三维能力、复杂空间分析或 AI 农事处方能力。
- 不让前端直接解析原始文件结构；所有页面只通过后端标准化 API 获取数据。
- 不在仓库中提交临时客户样例数据、缓存文件、测试生成的真实文件或本地环境产物。

## 演示路径

1. 启动后端服务：`backend\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --reload`
2. 启动前端服务：`npm --prefix frontend run dev`
3. 打开场景驾驶舱：`/overview`，说明当前为程序生成的模拟数字孪生场景。
4. 进入 Cesium 地图孪生：`/map-twin`，展示地块边界、指标着色、筛选和点击详情。
5. 打开地块画像：`/plot-detail/demo-ricefield-2025-A04`，展示单地块指标快照、趋势和质量状态。
6. 进入指标对比：`/metric-compare`，展示地块排行、区域对比、状态分布和明细表。
7. 进入预警分析：`/warnings`，展示缺失、异常、错误等质量问题及地块联动。
8. 进入系统说明：`/system-docs`，收束项目定位、数据来源、功能边界和文档入口。
9. 如需 3 分钟口播，可配合 `docs/DEMO_SCRIPT.md` 使用。

## 数据合规检查

- 仓库中不得出现真实客户 Excel、真实 GeoJSON、客户 PDF、客户图片或其他可识别来源的数据材料。
- 默认演示场景必须标记为模拟数据，数据来源应保持程序生成或脱敏演示语义。
- 指标必须先进入指标字典，再进入观测和展示链路；前端不得自行解释原始字段。
- 观测数据应保持长表结构，至少包含地块编号、指标编码、指标值、观测时间、观测批次、数据来源和质量标记。
- 每个观测批次都应有质量状态或质量问题记录，不能隐藏缺失、异常、未匹配或错误类问题。
- API 和页面不得暴露 `source_file`、`raw_sheet`、`raw_cell` 等真实文件追溯字段。
- 旧版导入导出接口应继续保持不可用状态，避免第一阶段被误解为文件导入平台。

## 已知风险

- Cesium 卫星底图依赖外部底图服务和网络状态；发布演示时应提前打开地图页确认底图、地块边界和图例加载正常。
- 前端构建会保留 Cesium 与 Ant Design Vue 相关的大 chunk 提示，这是当前第一阶段已知体积风险，不影响构建成功。
- 部分本地环境可能因系统临时目录权限导致 Pytest 初始化失败，发布验证应使用仓库内 `--basetemp` 目录。
- 当前预警建议为演示级谨慎提示，不构成生产农事处方或真实诊断结论。
- PostGIS 正式数据层尚未纳入默认发布验证，不能把第一阶段发布描述为正式生产数据平台。

## 进入第二阶段前置条件

- 明确第二阶段范围并形成书面确认，避免在第一阶段发布后直接追加未评审能力。
- 完成真实数据合规评审，确认客户授权、脱敏要求、存储边界、访问权限和删除机制。
- 定义文件导入契约、指标字典扩展规则、长表转换规则、批次追溯字段和质量规则。
- 若接入正式空间数据，先确认 PostgreSQL + PostGIS 数据模型、迁移脚本、部署方式和回滚方案。
- 更新 API 契约、数据模型、用户手册、导入指南和测试夹具，再实现任何导入能力。
- 补充第二阶段浏览器回归、后端测试、前端服务测试和构建验证清单。
- 在确认合规数据和测试闭环前，不把 Excel、GeoJSON、PDF、图片导入纳入主演示路径。
