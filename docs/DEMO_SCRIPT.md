# 3 分钟演示脚本

## 演示目标

本脚本用于在 3 分钟内完整演示“稻田智研平台”第一阶段能力，重点讲清楚三个问题：

1. 平台如何把稻田场景、地块、指标、时间和质量状态组织成数字孪生对象。
2. 平台如何通过 Cesium 地图、地块画像、指标对比和预警分析完成科研展示闭环。
3. 当前阶段只使用后端程序生成的模拟数据，不接入、不保存、不展示真实客户数据。

第一阶段演示边界必须保持清晰：默认场景为 `demo-ricefield-2025`，数据由后端程序生成，包括 8 个示例地块边界、11 个演示指标、45 天时序观测和 6 条预警事件。演示过程中不引入 Excel、GeoJSON、PDF、图片导入主线，也不展示任何真实客户资料、真实采集文件或可识别来源数据。

## 准备工作

1. 启动后端服务：

   ```powershell
   backend\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --reload
   ```

2. 启动前端服务：

   ```powershell
   npm --prefix frontend run dev
   ```

3. 打开前端首页，建议从 `/overview` 开始演示。
4. 浏览器建议使用桌面宽屏视口，提前确认地图、图表和表格可以正常加载。
5. 演示前确认不要打开本地 Excel、GeoJSON、PDF、图片或客户资料目录；如被问到数据来源，统一说明“当前第一阶段为后端程序生成的模拟演示数据，真实数据接入属于后续合规扩展”。

## 页面顺序

| 时间 | 页面 | 目标 |
|---|---|---|
| 0:00-0:30 | 场景驾驶舱 | 说明平台定位、当前模拟场景、地块数量、指标数量、预警数量和健康度 |
| 0:30-1:15 | Cesium 地图孪生 | 展示程序生成地块边界、指标着色、地块点击详情和趋势联动 |
| 1:15-1:45 | 地块画像 | 展示单个地块的数字档案、多指标快照、趋势和观测批次 |
| 1:45-2:15 | 指标对比 | 展示按指标、日期、区域对地块状态进行横向比较 |
| 2:15-2:45 | 预警分析 | 展示缺失、异常和错误如何进入质量状态与风险提示 |
| 2:45-3:00 | 系统说明 | 收束第一阶段边界、数据来源和文档体系 |

## 讲解词

### 场景驾驶舱

“这是稻田智研平台的场景驾驶舱。当前演示的是第一阶段数字孪生闭环，场景编号是 `demo-ricefield-2025`。这里的地块、指标、观测时间和预警全部来自后端程序生成的模拟数据，不是真实客户数据。驾驶舱把 8 个示例地块、11 个指标、45 天观测和当前风险状态汇总到一个入口，方便答辩时先建立整体认知。”

### Cesium 地图孪生

“进入 Cesium 地图后，可以看到程序生成的示例地块边界。地块颜色由当前选择的指标值和质量状态决定，绿色代表正常，黄色代表关注，橙色或红色代表预警或严重。点击任意地块，右侧会出现地块编号、区域、指标值、观测批次和数据来源，下方趋势图会随地块联动。这里演示的是空间定位和指标状态感知，不包含 GeoJSON 导入、地块编辑或复杂空间分析。”

### 地块画像

“从地图进入地块画像后，平台把一个地块组织成数字档案。顶部是地块身份和最近观测信息，中间展示基础信息、多指标快照和单指标趋势，底部展示观测批次、预警与建议。部分字段明确是模拟字段，用于展示数据结构和分析能力，不伪装成真实田间记录。”

### 指标对比

“指标对比页用于横向比较同一天、同一个指标下不同地块的状态。这里可以切换指标、日期和区域，查看均值、最高值、最低值、异常地块数、排行图、区域对比和明细表。这个页面说明平台不是只看单个地块，而是可以支持科研汇报里常见的地块间对比分析。”

### 预警分析

“预警分析页展示当前模拟观测中发现的缺失、异常和错误等质量问题，并把它们转换成用户可理解的风险提示。页面包含风险统计、类型分布、严重程度分布、地图定位、最新预警和明细表。这里的建议措施是谨慎提示，真正落地时仍需要结合田间记录和合规数据源判断。”

### 系统说明

“最后用系统说明页收束边界。当前版本重点是演示数字孪生可视化闭环：场景、地块、指标、时间、质量状态和预警联动。第一阶段不接入 Excel、GeoJSON、PDF、图片或真实客户数据；后续如果接入真实数据，会先经过指标字典、标准化长表、批次追溯和质量规则，再进入同一套 API 和前端页面。”

## 点击动作

1. 从场景驾驶舱点击“进入 Cesium 地图孪生”。
2. 在地图页保留默认指标和最新日期，点击一个颜色明显的地块。
3. 查看右侧地块详情，短暂停留在下方趋势图和最新观测记录。
4. 点击“查看画像”进入当前地块画像。
5. 在地块画像页切换一次趋势指标或时间范围，展示指标快照和趋势联动。
6. 通过侧边导航进入“指标对比”，切换一个指标后点击“查询”。
7. 点击排行图中的一个地块或表格中的“定位地图”，说明页面间联动能力；如时间紧张，只口头说明，不必实际跳转。
8. 进入“预警分析”，点击一条最新预警或地图上的风险地块，展示列表和明细表高亮。
9. 进入“系统说明”，指向“当前数据说明”和“系统边界”区域作为结束。

## 预期画面

- 场景驾驶舱：顶部显示稻田数字孪生演示场景，KPI 卡片展示地块数量、指标数量、预警数量、观测天数和健康度；页面中部有关键指标、风险分布、区域状态和重点关注地块。
- Cesium 地图孪生：地图中显示 8 个示例地块边界和地块编号，地块按指标状态着色；点击地块后右侧详情、趋势图、关键指标和观测记录同步刷新。
- 地块画像：页面标题显示“地块画像 / 地块编号”，摘要卡展示地块身份，中部三栏展示基础信息、指标快照和趋势图，底部显示观测批次和预警建议。
- 指标对比：统计卡、排行图、区域对比、状态分布和明细表围绕当前指标刷新；表格中保留地块画像和地图定位入口。
- 预警分析：风险统计、预警类型分布、严重程度分布、预警地图、最新预警和明细表同时展示；点击预警或地块后对应记录高亮。
- 系统说明：展示平台定位、当前数据说明、数字孪生构建流程、功能边界、未来演进方向和文档索引。

## 注意事项

- 不要说“已接入真实农场数据”“已导入客户文件”或“已完成 Excel/GeoJSON/PDF/图片导入”。
- 不要在演示中打开客户原始文件、真实图片、真实 PDF、真实 Excel 或真实 GeoJSON。
- 不要把地图边界描述为真实测绘边界，应表述为“后端程序生成的示例地块边界”。
- 不要把预警建议描述为自动处方或生产决策，应表述为“基于模拟质量状态的谨慎提示”。
- 如果地图底图加载较慢，可以重点讲地块 polygon、颜色、右侧详情和趋势联动；第一阶段能力不依赖复杂三维资产。
- 如果被问到真实数据接入路径，回答重点是：后续必须先进入指标字典，转换为标准化长表，保留地块编号、指标编码、指标值、观测时间、观测批次、数据来源和质量标记，再通过标准 API 进入前端。
