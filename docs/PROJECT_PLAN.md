# 稻田智研平台项目计划

## 项目定位

本项目是面向大创答辩、项目演示和科研展示的稻田数字孪生可视化平台。第一阶段不做数据导入系统，不处理 Excel，不保存真实 GeoJSON 或客户资料，而是通过程序生成的可信模拟场景展示平台能力。

核心目标：

1. 用场景驾驶舱讲清楚“数字孪生对象、时间、地块、指标和状态”。
2. 用 Cesium 地图展示地块边界、指标着色和点击联动。
3. 用图表和表格展示指标对比、地块画像和预警分析。
4. 保持清晰的数据模型、API 和文档基准，便于后续接入合规数据源。

## 第一阶段范围

必须完成：

- 后端程序生成默认场景 `demo-ricefield-2025`。
- 程序生成 8 个示例地块边界，分属试验一区和试验二区。
- 生成 11 个演示指标、45 天时序观测和质量预警。
- 提供场景、指标、地块、日期、地图图层、地块摘要、地块趋势、指标对比和预警 API。
- 前端形成六页答辩闭环：场景驾驶舱、Cesium 地图孪生、地块画像、指标对比、预警分析、系统说明。
- 文档同步成为后续执行项目的基准。

明确不做：

- Excel、GeoJSON、PDF、图片等文件导入。
- 数据导入中心和导入质量报告。
- 真实客户数据或可识别来源数据。
- 权限系统、自动报告、多项目管理、复杂三维资产和复杂空间分析。

## 技术路线

| 层级 | 方案 |
|---|---|
| 前端 | Vue 3、TypeScript、Vite、Vue Router、Pinia、Ant Design Vue、ECharts、CesiumJS、Axios |
| 后端 | FastAPI、Pydantic、SQLAlchemy、Alembic、Pytest |
| 默认数据 | 程序生成模拟场景 |
| 可选正式层 | PostgreSQL + PostGIS |
| 部署 | Nginx、Docker Compose |

默认演示必须开箱即用，不依赖 PostGIS。PostGIS 只作为正式数据层保留，使用同一套 API 契约。

## 成功标准

- 打开前端后能在 3 分钟内完成答辩演示主线。
- Cesium 地图能展示地块、指标色阶、点击详情和趋势。
- 预警分析能解释缺失、异常和错误如何进入系统状态。
- 文档不再把导入报告、Excel 或文件治理作为第一阶段主线。
- 后端测试、前端服务测试和前端构建通过。
